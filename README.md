# ecommerce-lawc
Proyecto de e-commerce para Laboratorio de Aplicaciones Web Cliente


TECNOLOGIAS:

-HTML5: estructura de la página web.
-CSS3: estilos personalizados y diseño responsive.
-JavaScript (ES6+): lógica de la aplicación y generación dinámica de productos.
-Bootstrap 6 Alpha: componentes visuales y diseño adaptable.
-Fake Store API: API externa utilizada para obtener los productos.
-Fetch API: solicitudes HTTP para obtener los datos de los productos.
-Git y GitHub: control de versiones y trabajo colaborativo.
-GitHub Desktop: gestión del repositorio y sincronización de cambios.
